# INC-00X : Titre de l'incident
| | |
|---|---|
| **Date** | AAAA-MM-JJ |
| **Type** | Simulation (exercice) |

| **Durée d'indisponibilité** | ___ |
## Symptômes
Ce que voit l'utilisateur ou le monitoring.
## Détection
Comment l'incident a été détecté (alerte, dashboard, logs). Délai entre le début de la panne et la
détection.
## Diagnostic
Les commandes lancées, dans l'ordre, et ce qu'elles ont montré.
## Résolution
Les actions menées. Durée totale de la résolution (RTO mesuré).
## Cause racine
Pourquoi cela s'est produit (pas seulement "quoi").
## Impact
Données perdues (RPO), requêtes en erreur, durée.
## Prévention
Actions concrètes pour éviter ou détecter plus vite la prochaine fois.
